如何設定 Firebase?

本系統為無伺服器架構，資料完全儲存在您個人的 Firebase 專案中，確保隱私與免費。

  1. 前往 Firebase 控制台 建立新專案。
  2. 在專案中新增一個 Web 應用程式 (``)。
  3. 啟用 Firestore Database，並將安全規則設為允許讀寫 (測試期)。
  4. 啟用 Authentication 中的 匿名登入 (Anonymous)。
  5. 在專案設定中，複製 firebaseConfig 內的內容。
  6. 回到本系統點擊「設定連線資訊」並貼上。
// 請複製引號內的屬性
apiKey: "AIzaSy...",
authDomain: "...",
...
appId: "1:123..."

系統連線設定

請從您的 Firebase 專案複製 firebaseConfig 物件 { 和 } 之間的六行內容 (Key: Value)貼到下方。
⚠️ 請勿貼上大括號 {} 或變數宣告 (const...)。

預設密碼為 6501。為了防止學生按 F12 偷看原始碼，系統採用 SHA-256 單向加密技術，真實密碼不會暴露在程式碼中。
